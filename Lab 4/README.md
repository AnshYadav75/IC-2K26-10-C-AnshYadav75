# Lab 4 – Arrays in C Programming

## Introduction
This lab focuses on understanding and implementing one-dimensional and two-dimensional arrays in C programming.

## Programs

### 1D Array Programs
1. Input and Display Array Elements
2. Find Sum of Array Elements
3. Find Average of Array Elements
4. Find Largest Element in an Array
5. Find Smallest Element in an Array
6. Count Even and Odd Elements
7. Search an Element Using Linear Search
8. Reverse an Array
9. Copy One Array into Another
10. Sort Array in Ascending Order

### 2D Array Programs
11. Addition of Two Matrices
12. Transpose of a Matrix

## Problem Statements
- Write a program to input and display array elements.
- Calculate the sum and average of array elements.
- Find the largest and smallest elements in an array.
- Count even and odd elements in an array.
- Search for an element using linear search.
- Reverse and copy an array.
- Sort array elements in ascending order.
- Perform addition of two matrices.
- Find the transpose of a matrix.

## Approach / Algorithm
1. Declare an array with the required size.
2. Take input from the user using loops.
3. Access array elements using their index positions.
4. Perform the required operations.
5. Display the final result.
