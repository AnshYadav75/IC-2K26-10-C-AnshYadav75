## Problem Statements

- Write a C program to find the LCM of two numbers.
- Write a C program to calculate the sum of first N natural numbers.
- Write a C program to swap two numbers without using a temporary variable.
- Write a C program to check a character.
- Write a C program to find the factorial of a number.
- Write a C program to find the GCD of two numbers.
- Write a C program to check whether a number is an Armstrong number.
- Write a C program to check whether a number is a palindrome.
- Write a C program to generate the Fibonacci series.

## Approach / Algorithm

1. Understand the given problem.
2. Declare the required variables.
3. Take input from the user.
4. Apply the required mathematical or logical operations.
5. Display the result.
